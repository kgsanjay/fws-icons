Read README.md and START-CODEX.txt. Use the queue; never regenerate completed icons.
For new master icons, use SVG FIRST: author native vector geometry directly, inspect it, then export the PNG. The user explicitly approved SVG authoring instead of raster generation/tracing. Do not use the image generator or VTracer for new master artwork. Preserve existing raster-generated/traced artwork. Never use stock icons or embed raster images in SVG. No API fallback, paid external backend or model changes without the user's explicit choice. Native SVG-first production does not require an image-generation tool.
Process requested batches in order with one operator. Use `python queue.py --root catalog packet BATCH` for native SVG instructions. Record each new authoring attempt with `attempt ID`, save an editable SVG under catalog/work/, visually review at small and large sizes, then run `accept-svg ID PATH --size 1024`. Record rejected authoring with `fail ID reason`; maximum three recorded authoring attempts per icon. Do not regenerate completed artwork or change progress to bypass validation. The old PNG `accept` and `vectorize` commands remain for legacy work; new master entries reject PNG-first acceptance/tracing.
Native SVGs use a square viewBox (prefer 128), fill="none", consistent 2.5-unit rounded strokes, #202123 / #C31E25, and generous transparent margins. Use paths, circles, rectangles and simple curves; no CSS, transforms, text, raster, external resources or effects. Keep all curves and joins smooth, avoid touching contours, align repeated elements, and inspect optical spacing. Native validation checks a uniform stroke width and safe geometry, PNG checks verify transparency/colors/margins, and pair validation requires the PNG to be a direct SVG render. These checks cannot guarantee visual quality; inspect both the source and rendered PNG.
Bundle complete batches using `bundle BATCH`; bundles support historical traced pairs and new native SVG/PNG pairs. Never retrace completed master SVGs. Stop for an actual blocker, user pause or exhausted attempts. Preserve all work and report failures accurately.

After each batch continue to the next if user requested all; do not request routine approval between batches. Stop for a real blocker, user pause, or exhausted generation attempts. Report failed IDs at the end. Never promise a single session will finish the entire list.
