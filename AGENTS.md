# FWS Icon Factory
Read README.md and START-CODEX.txt. Use the queue; never regenerate completed icons.
Use the available imagegen skill and actual image generation tool, one call per service. Never substitute stock icons or drawing code for generated artwork. After real PNG generation, trace the PNG into genuine SVG paths using vectorize.py; never embed raster images in SVG. No API fallback, paid external backend or model changes without the user's explicit choice. If no built-in image generation exists, stop and explain exactly what is missing.
Process requested batches in order with one operator (no simultaneous queue writers). Run `python queue.py attempt ID` just before each generation, inspect prompt file, generate actual transparent PNG, visually inspect, then `python queue.py accept ID PATH`, which validates the PNG and automatically traces and validates its paired SVG before marking the item complete. If technical validation fails, record `python queue.py fail ID "reason"`; maximum 3 recorded generation attempts. For an interrupted in_progress item first inspect its expected output before making another paid call. Do not use fake files or change state to bypass validation.
Call `python queue.py bundle BATCH` for fully complete batches. Deliver ZIP and preview locations; never claim generation complete based only on API success. queue.py checks transparency, square PNG, margins and color presence; SVG checks require exact palette paths and at least 0.95 per-color raster overlap with the PNG; you must inspect subject, stroke consistency, duplicate symbols, text and visual defects separately. At quota/auth/rate-limit blockers, pause and report; do not mark unavailable generation as a defective icon. Keep status accurate and resumable.
If reference.png exists, inspect it and use as a style reference. Keep original list order and original subject meanings. Prompt overrides are allowed only to make the correct subject clearer. Log any changes in work/notes.md.
After each batch continue to the next if user requested all; do not request routine approval between batches. Stop for a real blocker, user pause, or exhausted generation attempts. Report failed IDs at the end. Never promise a single session will finish the entire list.

Deliver both PNG and SVG for every icon. For older completed PNGs, run `python queue.py vectorize BATCH` without regenerating images or changing generation attempt counts. Bundling requires valid pairs. Inspect the SVG render as well as the original PNG; traces contain filled outlines, not semantic editable stroke centerlines.
